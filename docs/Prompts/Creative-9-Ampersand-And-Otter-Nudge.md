## Project Context

`src/pages/creative/index.astro`: the fourth `<CreativeCard>` has `title="Cauldron &amp; Tome"` (line ~90). In Astro, a string passed as a component prop or inside `{...}` is a plain JavaScript string and is HTML-escaped automatically on output, so the source must contain a literal `&`; a pre-escaped `&amp;` is escaped again and renders as the characters `&amp;`. Plain-text children and static attribute values written directly in markup follow normal HTML rules (a bare `&` followed by a space is valid there). The otter image classes (same file, line ~39) include `md:-translate-y-[40%]` (the image is `md:absolute` inside a wrapper, so changing its translate does not change layout flow).

Relevant files:
- `CLAUDE.md` — standing instructions and build commands
- `src/pages/creative/index.astro` — the only file to change
- `src/components/CreativeCard.astro` — read only: confirm how `title` is rendered (`{title}` expression, auto-escaped)
