**2. Canonical URLs.** Add a canonical `<link>` tag to `BaseLayout.astro`'s `<head>`, computed from `Astro.site` + `Astro.url.pathname` (Astro's standard pattern for this — verify the exact API against this Astro version, `^7.2.0`, rather than assuming a specific syntax from memory). **3. Sitemap.** Add the official `@astrojs/sitemap` integration (`npx astro add sitemap` is the standard installer if available in this environment; otherwise `npm install @astrojs/sitemap` plus the manual `astro.config.mjs` wiring — check which path actually works here). **Exclude `/404` from the sitemap** — it already carries `noindex`, and a 404 page has no business being listed as a crawlable/indexable URL. Use the integration's own filtering mechanism for this rather than a manual post-build edit.

**4. `robots.txt`.** Add `public/robots.txt`:

```
User-agent: *
Allow: /

Sitemap: https://clockworkotterfoundry.com/sitemap-index.xml
```

(Confirm the actual sitemap filename/URL the integration generates — `sitemap-index.xml` is `@astrojs/sitemap`'s default, verify rather than assume.) **Do not `Disallow: /404`** — this is a deliberate choice, not an oversight: disallowing a page in `robots.txt` prevents crawlers from ever reaching it to *see* its `noindex` meta tag, which can paradoxically cause it to stay indexed (with no snippet) if anything ever links to it externally. Letting crawlers reach `/404` and honor its existing `noindex` tag is the correct mechanism; don't stack a second, conflicting one.

**5. Open Graph tags.** Add `og:title`, `og:description`, `og:type` (`website`), and `og:url` (same as the canonical URL) to `BaseLayout.astro`, derived from the existing `title`/`description` props — no new content needed for these three. Same `og:image` URL for every page (a single site-wide brand image, not per-page variants — nothing in this repo has per-page imagery to draw from).
